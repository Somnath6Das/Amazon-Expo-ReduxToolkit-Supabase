npx expo install --fix 


# upload image to supabase
i. enable public bucket

# add RLS policy
ii. Go to Supabase dashboard
Navigate to your project → Storage → Buckets → user-data.

iii. Click on the "user-data" bucket
In the bucket settings, make sure "Public" is turned off (for secure apps), and "RLS" is enabled.

iv. Click on the "Policies" tab
v. Policy Name: Allow anon upload

vi. Operation: INSERT
vii. Target Role to Select: anon

viii. sql field: 
auth.role() = 'anon'
